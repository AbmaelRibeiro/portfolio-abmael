Ativar a IA comercial

A IA lê apenas dados autorizados para o vendedor e gera sugestões. Ela não envia mensagens, não concede desconto e não finaliza pedidos.

A chave da API é armazenada no Supabase Vault. O modelo é configurável; para alto volume, o campo vem pré-preenchido com gpt-5.6-luna.
